# ecnn-diff

#### Article:   <small><strong>Equivariant dissipative generators for differential systems</strong>  <a href="https://doi.org/10.1016/j.cam.2026.117584"><img src="https://cdn.simpleicons.org/doi/2dd4bf" alt="DOI" height="14" align="absmiddle"></a>  <a href="https://doi.org/10.1016/j.cam.2026.117584"><img src="https://cdn.simpleicons.org/zenodo/2dd4bf" alt="Zenodo" height="14" align="absmiddle"></a>  <a href="https://drive.google.com/drive/folders/1DPsSIUbaE4k2ttw2Wi_G0KwfF2cu6Tqm?usp=sharing"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/google/google-original.svg" alt="Google Drive" height="14" align="absmiddle"></a></small>

Experiments on periodic reaction--diffusion systems evaluate the correction of perturbed and data-identified linear generators under simultaneous equivariance and dissipativity constraints. The EqDiss implementation uses mass-matrix whitening, finite-group Reynolds averaging, symmetric eigendecomposition, and spectral clipping to compute the nearest admissible generator in the weighted Frobenius metric. Equivariant experiments use dihedral group actions generated by periodic rotations and reflections. The supplied profiles include multiple spatial resolutions, perturbation scenarios, regression-based identification, and random seeds. Numerical quality is assessed using generator error, equivariance defect, dissipativity margin, spectral stability, trajectory error, contraction, and nonexpansiveness diagnostics. The implementation also compares EqDiss with Stable-SCA and $\Omega$-stable matrix corrections using the same reaction--diffusion test problems. The experiments additionally record computational time and memory complexity, enabling quantitative analysis of accuracy, equivariance, dissipativity, convergence, stability, and cost.
