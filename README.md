# ecnn-diff

#### Article:   <small><strong>Equivariant dissipative generators for differential systems</strong>  <a href=""><img src="https://cdn.simpleicons.org/doi/2dd4bf" alt="DOI" height="14" align="absmiddle"></a>  <a href=""><img src="https://cdn.simpleicons.org/zenodo/2dd4bf" alt="Zenodo" height="14" align="absmiddle"></a>  <a href="https://drive.google.com/drive/folders/1DPsSIUbaE4k2ttw2Wi_G0KwfF2cu6Tqm?usp=sharing"><img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/google/google-original.svg" alt="Google Drive" height="14" align="absmiddle"></a></small>

Experiments on periodic reaction–diffusion systems evaluate the correction of perturbed and data-identified linear generators under simultaneous equivariance and dissipativity constraints. EqDiss uses mass-matrix whitening, Reynolds averaging, symmetric eigendecomposition, and spectral clipping to compute the nearest admissible generator in the weighted Frobenius metric, retaining the averaged skew part. The main study uses dihedral actions generated by rotations and reflections, four scenarios, five dimensions from 64 to 1024, and 20 matched seeds, yielding 400 instances. EqDiss is compared with DSDP, BVLS, SCS, PDHG, CVXOPT, ADMM, Clarabel, OSQP, Dykstra, and Spectral basis, producing 4400 evaluations of the same joint projection problem. Diagnostics include generator and trajectory errors, correction norm, equivariance defect, dissipativity margin, contraction, and solution and objective gaps. A cyclic advection–diffusion–reaction study adds 300 instances at three noise levels to examine a nonzero skew component. Further checks examine mass conditioning and time integration. Measurements include runtime, peak resident memory, CPU package energy, and GPU board energy.
